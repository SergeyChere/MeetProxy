# Colab via the official tools

Read this only for the route "Colab via the official Colab CLI or skill". Instructions only and not
yet tried with MeetProxy: tell the user so.

- Use the official tool's own documented commands; do not guess commands it does not document.
  If it is not installed or not signed in, say so and stop (SKILL.md section 1) — do not install it
  without asking, and do not switch to the mailbox without the user's approval of that route.
- **Paid compute:** ask before every acquire of a paid runtime, with the expected time and the
  runtime type. If you cannot see or set a time limit for the session, say so before asking.
- A runtime you acquired is **owned**: release it when the campaign stops, then check with the tool
  that it is gone, and report *session released* with that evidence. If you cannot confirm it,
  report *unknown — please check Colab* and how.
- A disconnect is not a cancellation: after reconnecting, check what is still running before you
  start anything new.
- Results, records and honesty rules: SKILL.md sections 2–4.
